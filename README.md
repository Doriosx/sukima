# Клуб «Сукима»

Готовая страница неофициального фан-сайта о Юкари Якумо из Touhou Project.
Сайт: https://doriosx.github.io/sukima/

Файл `index.html` собирается автоматически, править его здесь бесполезно:
исходники, сборка и документация хранятся в отдельном репозитории.
